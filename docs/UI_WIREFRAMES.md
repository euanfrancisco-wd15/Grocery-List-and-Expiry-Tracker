# GroPanda UI Wireframes

![GroPanda logo](../assets/images/gropanda_logo.png)

This document contains only the app's mobile UI wireframes. It does not include
system architecture, database schema, or setup instructions. The screens are
illustrative layouts based on the current Flutter app; sample values and
long-page scrolling are representative.

Printable copy: [UI_WIREFRAMES.pdf](UI_WIREFRAMES.pdf). Regenerate it from the
repository root with:

```sh
python3 docs/export_system_design_pdf.py docs/UI_WIREFRAMES.md docs/UI_WIREFRAMES.pdf
```
